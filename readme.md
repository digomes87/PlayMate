# PlayMate

Bebendo um mate.

**Mate no Pampa**: a pixel-art scene of a gaucho drinking chimarrão by the fire while the herd grazes on the pampa. Plain HTML, CSS and JavaScript modules, no build step.

- Live: https://digomes87.github.io/PlayMate/
- Run locally: `npm start`, then open http://localhost:8000
- Tests: `npm test`
- Branching and delivery: [docs/branching.md](docs/branching.md)
